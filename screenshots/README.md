# Application Screenshots

This directory stores visual verification and demonstration screenshots of the **Linux Automated Website Uptime Monitoring System**.

## Expected Screenshots

1. `01_overview_dashboard.png`: The main infrastructure overview dashboard displaying total monitors, operational vs. down counters, 24-hour latency trend chart, and status tables.
2. `02_monitors_list.png`: The monitors inventory showing registered websites, operational badges, check intervals, and action triggers.
3. `03_website_detail_analytics.png`: Individual website analytics with latency charts, uptime percentages, and recent health check logs.
4. `04_incident_management.png`: Active outages and resolved incident records displaying calculated downtime durations and root causes.
5. `05_system_telemetry.png`: Live Fedora Linux host resources (CPU, RAM, Disk, System Uptime) retrieved via `psutil`.
6. `06_csv_reports.png`: Reports filtering interface and CSV export functionality.
